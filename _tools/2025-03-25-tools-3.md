> 📈 本文结合 InSAR 形变与地下水时间序列，介绍连续小波变换（CWT）、交叉小波变换（XWT）和小波相干（WTC）的基本原理、MATLAB 使用方法及结果解读。附完整代码与示例数据，方便复用。

---

## 1. 背景简介

在 InSAR 时间序列分析中，地表形变通常包含长期趋势、季节性波动和短期扰动。例如，地下水开采与补给可能引起地层压缩和回弹，使形变时序呈现一定的周期性。

这些周期信号的强度和持续时间并不一定保持稳定：年周期可能只在部分时段明显，也可能随水文条件变化而增强或减弱。

傅里叶分析能够识别信号整体的频率组成，而**小波变换可以进一步揭示某种周期在什么时间出现，以及其强度如何随时间变化**。

本文介绍以下三种分析方法：

| 方法 | 英文名称 | 主要作用 |
| :--- | :--- | :--- |
| 连续小波变换（CWT） | Continuous Wavelet Transform | 分析单条时间序列的局部周期及功率分布 |
| 交叉小波变换（XWT） | Cross Wavelet Transform | 分析两条时间序列的共同功率及相位关系 |
| 小波相干（WTC） | Wavelet Coherence | 分析两条时间序列在局部时间和周期范围内的相干程度 |

---

## 2. 小波变换的基本原理

### 2.1 连续小波变换（CWT）

连续小波变换通过对母小波进行伸缩和平移，将时间序列展开到时间—尺度空间：

$$
W_x(s,\tau)=\frac{1}{\sqrt{s}}
\int_{-\infty}^{+\infty}
x(t)\psi^{*}\left(\frac{t-\tau}{s}\right)\mathrm{d}t
$$

其中：

- \(x(t)\)：待分析的时间序列；
- \(\psi\)：母小波函数；
- \(s\)：尺度参数，控制小波的伸缩；
- \(\tau\)：时间位置，控制小波沿时间轴平移；
- \(*\)：复共轭。

小尺度通常对应短周期，大尺度通常对应长周期。尺度与周期之间的换算关系取决于所选母小波。

本示例使用工具箱默认的 **Morlet 小波**，分析时间序列中的局部振荡特征。

小波功率定义为：

$$
P_x(s,\tau)=|W_x(s,\tau)|^2
$$

功率越大，说明对应时间和周期附近的波动越强。

对于 InSAR 形变时序，CWT 可以帮助判断年周期或其他周期是否存在，以及这些周期的强度是否随时间变化。

### 2.2 交叉小波变换（XWT）

对于两条时间序列 \(x(t)\) 和 \(y(t)\)，交叉小波变换定义为：

$$
W_{xy}(s,\tau)=W_x(s,\tau)W_y^{*}(s,\tau)
$$

交叉小波功率为：

$$
P_{xy}(s,\tau)=|W_{xy}(s,\tau)|
$$

XWT 用于识别两条时序在什么时间、什么周期范围内具有较高的共同功率，并通过相位箭头展示两者的相位关系。

例如，可以利用 XWT 检查 InSAR 形变与地下水时序是否具有共同的年周期变化。

> 💡 **共同功率较高，不代表局部相干一定较高。** 因此，通常需要结合 WTC 进一步分析。

### 2.3 小波相干（WTC）

小波相干通过对平滑后的交叉小波谱进行归一化，描述两条时序在局部时间—尺度空间中的关联程度。

平方小波相干表示为：

$$
R^2(s,\tau)=
\frac{
\left|S\left(s^{-1}W_{xy}(s,\tau)\right)\right|^2
}{
S\left(s^{-1}|W_x(s,\tau)|^2\right)
S\left(s^{-1}|W_y(s,\tau)|^2\right)
}
$$

其中，\(S\) 表示时间和尺度方向上的平滑算子。

其取值范围为：

$$
0\leq R^2(s,\tau)\leq 1
$$

- 接近 1：对应时间和周期附近的相干较高；
- 接近 0：对应区域的相干较弱。

**XWT 关注共同功率，WTC 关注归一化后的局部相干，两者相互补充。**

> 高相干或稳定的相位关系本身不能证明因果关系。解释地下水与形变之间的联系时，仍需结合含水层结构、抽水记录和其他独立观测。

其中：

| 文件或目录 | 说明 |
| :--- | :--- |
| `data/InSAR_disp.txt` | InSAR 形变时间序列 |
| `data/groundwater.txt` | 地下水时间序列 |
| `script/` | 小波分析及辅助函数 |
| `waveletdemo.m` | CWT、XWT 和 WTC 基础演示脚本 |

### 3.2 输入数据格式

两组数据均采用**无表头的两列数值格式**：

```text
时间    观测值
```

例如：

```text
2018.001370     2.739904404
2018.034247     6.505495563
2018.067123    11.031699060
```

第一列为时间，第二列为观测值。

本示例时间采用**小数年**，因此输出周期的单位也为年：

| 周期值 | 对应含义 |
| :--- | :--- |
| 0.5 | 约半年 |
| 1 | 约一年 |
| 2 | 约两年 |

形变和地下水观测值的单位应根据原始数据说明确定。

> 💡 **周期单位由输入时间决定。** 如果输入时间单位是天，输出周期单位就是天；不能仅修改坐标轴标签完成单位转换。

### 3.3 分析前的数据检查

本工具箱面向规则采样时间序列，运行前应检查：

1. 时间是否严格递增，是否存在重复日期；
2. 是否存在缺测值、无穷值或明显异常值；
3. 两条时序是否具有一致的采样间隔和对齐的时间网格；
4. 是否具有足够长的共同观测时段；
5. 是否需要根据研究目的去趋势。

对于不规则的 InSAR 观测，应先确定合理的重采样方案。插值可能影响功率、相干和相位，尤其应避免跨越较长缺测时段直接插值。

若重点研究季节性波动，可以考虑先去除长期趋势，并在结果说明中记录预处理方法。

## 4. MATLAB 脚本运行方法

### 4.1 设置路径与数据文件

解压后，将 MATLAB 当前目录切换至 `waveletdemo.m` 所在目录。

原始脚本使用文件名直接读取数据，而压缩包中的数据位于 `data/` 文件夹，因此建议将数据读取部分修改为：

```matlab
%% 加载工具函数和示例数据
root = fileparts(mfilename('fullpath'));

addpath(fullfile(root, 'script'));

seriesname = {'InSAR', 'Groundwater'};

d1 = load(fullfile(root, 'data', 'InSAR_disp.txt'));
d2 = load(fullfile(root, 'data', 'groundwater.txt'));
```

其中，`d1` 为第一条时序，`d2` 为第二条时序。后续相位领先关系也以这一输入顺序为准。


### 4.2 运行基础分析

完成路径和预处理设置后，在 MATLAB 中运行：

```matlab
waveletdemo
```

核心分析函数分别为：

```matlab
% 单条时间序列的连续小波变换
wt(d1);
wt(d2);

% 两条时间序列的交叉小波变换
xwt(d1, d2);

% 两条时间序列的小波相干
wtc(d1, d2);
```

原始演示脚本已将这些调用安排在不同图窗中，运行后依次生成 CWT、XWT 和 WTC 图。

WTC 的显著性估计涉及 Monte Carlo 计算，运行时间通常比前两项更长。

## 6. 交叉小波变换结果（XWT）

XWT 用于识别两条时序的共同功率及相位关系。

<div align="center">
    <img src="/files/tools/xwt.jpg" width="80%" alt="InSAR形变与地下水时间序列的交叉小波变换结果">
</div>

分析时可重点检查：

1. 共同功率主要集中在哪些周期；
2. 高共同功率区域是否持续存在；
3. 是否通过显著性检验；
4. 相位箭头是否具有相对稳定的方向。

### 6.1 相位箭头的含义

对于本代码包中的 `xwt(d1, d2)` 和 `wtc(d1, d2)`，函数注释给出的箭头约定如下：

| 箭头方向 | 相位关系 |
| :--- | :--- |
| → 向右 | 两条时序同相 |
| ← 向左 | 两条时序反相 |
| ↓ 向下 | 第一条时序领先第二条约 90° |
| ↑ 向上 | 第二条时序领先第一条约 90° |

本文以 InSAR 形变为第一条时序，地下水为第二条时序。

因此，向下箭头表示 InSAR 形变领先地下水约四分之一周期；向上箭头表示地下水领先 InSAR 形变约四分之一周期。

解释前应明确观测值的正负号约定。例如，地下水位高程升高与地下水埋深增大代表不同的变化方向，InSAR 位移也可能采用不同的正负号定义。

### 6.2 相位差如何换算为时间差？

在周期为 \(T\) 的位置，相位差 \(\phi\) 对应的有符号时间偏移为：

$$
\Delta t=\frac{\phi}{2\pi}T
$$

例如：

- 在年周期附近，90° 的相位差约对应 3 个月；
- 在半年周期附近，90° 的相位差约对应 1.5 个月。

若 `period` 的单位为年，`phase` 为“周期 × 时间”的相位矩阵，则可写为：

```matlab
% period：周期向量，单位为年
% phase：相位矩阵，单位为弧度
phase_lag_days = bsxfun(@times, phase / (2*pi), period(:)) * 365.25;
```

> **相位换算必须乘以对应周期。** 代码包中 `waveletdemo2.m` 使用的 `phase / (2*pi) * 365.25` 仅适用于周期为 1 年的位置，不能直接用于整个周期范围。相位具有模 \(2\pi\) 的歧义，换算值应结合显著性、周期及物理过程解释。

WTC 展示两条时序在不同时间和周期范围内的平方小波相干。

<div align="center">
    <img src="/files/tools/wtc.jpg" width="80%" alt="InSAR形变与地下水时间序列的小波相干结果">
</div>

图中相干值介于 0 和 1 之间。高相干区域表示两条时序在对应时间和周期附近具有较稳定的局部关系，但不一定具有较高共同功率。

建议结合以下条件解读：

- 相干值是否较高；
- 是否通过显著性检验；
- 是否处于边缘效应较小的范围；
- 相位方向是否相对稳定；
- 是否能够与实际水文地质过程相互印证。

> 本代码包的 WTC 绘图会隐藏平方相干低于 0.5 区域的箭头。**出现箭头不等于通过显著性检验**，仍需结合黑色显著性轮廓判断。

## 8. 💡 显著性检验与边缘效应

### 8.1 黑色轮廓代表什么？

在本工具箱的默认设置下，黑色轮廓用于标记相对于所采用红噪声背景模型的 **95% 显著性边界**。

CWT、XWT 和 WTC 的检验对象分别为单序列功率、交叉功率和相干，因此不能将三者的显著性简单等同。

局部通过检验，也不意味着已经控制了对整张时频图反复搜索所带来的多重比较问题。

### 8.2 什么是影响锥（COI）？

有限长度的时间序列在两端容易产生边缘效应，长周期分析尤其明显。影响锥（Cone of Influence，COI）用于标记这种影响的范围。

本工具箱中，可优先解释满足以下条件的区域：

$$
T\leq \mathrm{COI}(t)
$$

其中，\(T\) 为周期。

图中浅色遮罩覆盖的区域受边缘效应影响较大。即使出现高功率、高相干或显著性轮廓，也不能忽略这一限制。

此外，**采样间隔限制可分辨的短周期，观测时长限制可可靠分析的长周期**。讨论多年周期时，应确保记录覆盖足够多的振荡过程。
